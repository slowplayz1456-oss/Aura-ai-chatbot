Companion mode ⚡
Switches Aura into a fuller AI-companion persona, on standby 24/7 — he'll check in, keep track of things for you, and can log reminders. Say "Aura, go to sleep" / "ऑरा, सो जाओ" / "ઓરા, ઊંઘી જાઓ" to power him down, or "Aura, wake up" / "ऑरा, उठ जाओ" / "ઓરા, ઉઠી જાઓ" to bring him back online. Say "Aura, open WhatsApp" (or any of a dozen web apps) to launch it in a new tab — press Ctrl+M anytime to start listening.
Controls what language the mic listens for, and which "Aura" wake commands are recognized (English, Hindi, or Gujarati, e.g. "ઓરા, ઊંઘી જાઓ").

API settings

Add an API key to get real, generated responses instead of the built-in demo replies. Your key is stored only in this browser (localStorage) and is sent directly from your browser to the provider's API — never to any other server.

Toggle "Web search" from the + menu to let Aura look things up live (news, scores, current events). Image generation always uses a Gemini key, even if your chat provider is Anthropic — Claude's API doesn't generate images. Without a Gemini key, "Generate an image" falls back to a local generative-art placeholder so you can still try the feature offline — it draws an abstract illustration locally in your browser rather than a real photo.

"Generate a video" works the same way: with a Gemini key that has Veo access, Aura kicks off a real video generation job (this can take a minute or more). Without one, or if the video API isn't available on your key, it falls back to a short locally-drawn animated placeholder clip instead of a real video.

"Generate code" from the + menu asks Aura to answer with a runnable, syntax-highlighted code block — it works with either provider once a key is set, and falls back to a small local snippet library in demo mode.

No API key saved — using demo responses.

System check

Checks your browser and device for the things Aura relies on — mic, camera, voice, clipboard, storage, and connectivity. Nothing is sent anywhere; this all runs locally.
